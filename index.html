Sources, matching & calculation Verified headers and totals

Comparison baseline: 2025 original seats plus the supplied 2025 mid-counselling additions by default. Uncheck “Include 2025 additions” to compare only the original 2025 matrix. These are supplied snapshots, not a guarantee that both years represent the same counselling stage.

Seat counting: category columns are validated against each row’s total; category rows are summed once. Select one or more seat categories, including separate PwD variants. The 2025 Deemed file provides total seats only: those totals remain visible once when categories are selected and are labelled “Total only.” Category growth against a total-only component is left blank; the growth split covers comparable rows only. Grand-total rows are excluded and reconciled against the detail rows.

Matrix groups: DNB, Deemed and Central / All India follow the source file. Some All India records are labelled DNB under Institute Type despite listing MD/MS courses; these stay in the All India source group. Quotas are kept separate. Management/paid and self-financed merit labels are standardized.

College identity: institute codes are the primary match. Reviewed same-campus code aliases and missing-code resolutions are documented in the quality report. No fuzzy name matching is applied automatically. Other code changes can still look like new or missing institutions. Source codes and addresses are available on each college row. Selected campus matches use address evidence from the previously supplied 2024/2025 allotment workbooks.

States: explicit source states and institute addresses are used first. Reviewed enrichments use identifiable localities or exact normalized college names from the earlier allotment workbooks where every matching record agrees on the state. Remaining unknown states are retained in the results.

Courses: MCC course codes match renamed MD/MS labels across years; reviewed NBEMS spelling aliases are normalized. MD/MS, DNB and diploma courses stay separate. A new course at an existing college contributes to existing-college growth.

Growth split: seats at newly listed colleges + positive row changes at existing colleges − negative row changes at existing colleges − baseline seats at colleges absent from 2026 = net change. A quota redistribution can contribute both an increase and a decrease; the net accounts for both. College status is determined from the full baseline, before your branch, state, matrix or quota filters.
